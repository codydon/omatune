# Code of Conduct

OmaTune follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and patient, assume good intent, give feedback on the
code rather than the person, and don't harass anyone, whether in issues, pull
requests, discussions or anywhere else you represent the project.

## Reporting

If someone's behaviour worries you, contact the maintainers privately through
GitHub (a direct message to the repository owner), or use the Security tab's
private report if it's urgent. Reports are kept confidential. Maintainers may
remove comments, lock threads, or ban people who break this code, following
the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
